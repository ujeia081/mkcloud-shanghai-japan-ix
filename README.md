## 沪日 IX 到底是什么

先拆名字。“沪日”指上海到日本方向的跨境线路，“IX”指入口走互联网交换中心（IXP）互联，也就是 Mkcloud 官方所称的“上云互联优化入口”。

具体的工作方式是这样的：这台 VPS 的入口 IP 只在 IXP 内宣告，只有加入了对应交换中心的网络才能连进来——目前覆盖阿里云、腾讯云、百度云国内全网，以及火山云、华为云、UCloud 的华东区域。出口方向则是日本 BGP，接入了 NTT、Cogent、Telstra、HE 等多家国际运营商，并在 Equinix IX、JPIX、BBIX、JPNAP 等多个交换中心有接入，与 Google、Cloudflare 还有私有 PNI 对等互联。

换句话说，它不是一台随便谁都能 SSH 上去的日本服务器，而是一条“云厂内网 → 上海 → 日本”的专用通道。你从阿里云或腾讯云的机器连到入口，流量从日本 BGP 出口出去，端内参考延迟 25~28ms。

### 和沪日 IPLC 有什么区别

两条线路的端内延迟参考都是 25~28ms，真正差别在入口：

- **沪日 IPLC**：入口是上海电信直连，任何运营商网络都能接入，2 核 4GB 1TB 流量档月付 358 元。
- **沪日 IX**：入口只允许云厂 BGP 网络连入，流量档价格明显更低，1TB 档月付 166 元，2TB 档 268 元。

Mkcloud 官网首页对 IXP 专线产品线标注的起价是 158 元/月（这是深港等入口的起步价，沪日方向的起步价是 166 元/月）。第三方测评也印证了 IX 入口的价格逻辑：虎窝博客对 Mkcloud 沪日 IXP 产品的评测提到，IX 带宽成本低于三大运营商网络，所以售价比其他入口便宜、同价位流量给得更多。

除了流量计费的共享带宽套餐，沪日方向还有带宽计费的独享带宽产品，可定制 2-28 核、4-32G 内存、100-5000Mbps 独享带宽，有云服务器和独立物理服务器两种形态，适合对持续速率要求高的业务。独享产品按配置报价，需要在商店里选配。

## 买之前必须确认的三件事

沪日 IX 便宜是有条件的。下面这几条限制如果不先确认，买完很容易撞墙。

**第一，你得先有一台能连进 IXP 的云服务器。** 沪日 IX 只允许阿里云、腾讯云、百度云国内全网，以及火山云华东、华为云华东、UCloud 华东的网络连入。如果你的服务器是家宽、机房裸金属或者不在这个名单里的云，连入口都连不上。选型时要记住一点：IX 套餐的费用要加上前置云服务器的费用一起算。好在这类前置机通常不贵，各大云的轻量应用服务器或入门云主机就够用。NodeSeek 上有用户讨论这类玩法时也提到，前置用阿里云、腾讯云的轻量机器就行。

**第二，出口 IP 不是拿来对外服务的。** Mkcloud 交付的是 VPS，每台机器分配 1 个独立入口 IP 和 1 个独立出口 IP，你连入口使用、程序从日本出口向外访问。但出口不支持外部连入，官方明确说明不能用于公开建站、支付回调或对外游戏服务。而且 IP 属于服务器 IP，不保证原生、住宅或流媒体解锁。

**第三，实名和省级白名单是硬规则。** 所有产品需要中国身份信息实名，仅限个人或企业正规用途，禁止机场、回国等违规用途，违规会清退且不退款。IX 产品开通后只允许指定省份的 IP 连入（在附加选项里选），后续可以修改。

退款政策也要看清楚：仅支持质量问题退款，而且服务开通后不支持更换到其他地域产品。申请质量退款需要提供准确具体的延迟、速度数据。简单说，这是一笔“想清楚再买”的钱。

## 什么样的人适合沪日 IX

结合官方的选型说明和实际场景，沪日 IX 的适用人群相当清晰。

**做日区电商或本地化业务的团队**是最典型的用户。店铺后台、协作工具、素材上传、已授权 API 调用这些场景，对延迟和稳定性敏感，但流量不大，1TB 或 2TB 档就够用。前提是团队办公环境本身在阿里云、腾讯云等支持的云内网里——纯家宽办公环境连不上入口，这条线就无从谈起。

**研发和测试场景**也合适。在 VPS 上对日本服务发起客户端请求，测量成功率和任务耗时，IX 线路的日本 BGP 出口（接入 NTT、Cogent 等多家运营商，还有到 Google、Cloudflare 的 PNI 对等）在这类测试里表现稳定。

**持续大流量传输**则要看档位。6TB 以上档位给到了 1G 峰值和 4 核 8GB，30TB 以上是 2G 峰值。直播、图形类程序还要核对服务器配置是否够用。如果业务需要保证持续速率而不是峰值，那应该看独享带宽产品而不是流量计费套餐。

反过来说，这些人大概率不适合：本地网络不在支持云列表里的个人用户；需要拿 IP 对外建站、做支付回调的人；想要原生 IP 或流媒体解锁的人；以及没有日本方向真实业务、只是想“搞台机器玩玩”的人。这条产品线的定位是生产工具，不是玩具。

## 常见问题

**沪日 IX 和沪日 IPLC 怎么选？** 先看接入条件：你的网络环境能不能连 IXP 入口。能连，IX 在同配置下便宜 30% 左右（2TB 档：268 元 vs IPLC 的对应档位）；不能连，就直接看 IPLC。另外官方提醒，IX 不等于所有目标都直接对等，也不自动具备高防能力。

**海底光缆故障会影响专线吗？** 可能会。官方明确表示多运营商出口不能证明跨境线路有独立备份或保证无中断，高可用业务需要在下单前确认故障范围和保障约定。

**支持 IPv6 吗？** 官方现有资料不足以确认所有套餐的 IPv6 支持，业务必需的话下单前先问客服，别把双栈当默认能力。

**端内 25~28ms 是我访问日本网站的延迟吗？** 不是。这只是上海入口到日本出口这段的参考值，你本地到入口、日本出口到最终平台的耗时都要另算。

**质量怎么样？** 目前能查到的公开反馈比较有限。虎窝博客的沪日 IXP 测评认可其 IX 入口的性价比；NodeSeek 社区里能看到有用户转卖沪日 IX 高带宽档位、也有人分享用沪日 IX 搭配落地服务器做游戏加速的折腾记录，但也有用户表示自家其他线路（深港）体验一般。官方通知群披露过沪日链路优化和割接维护记录，说明这条线路仍在持续运营和维护中。
